# 特征比对器

高中信息科技《图像识别的过程》课堂演示程序。

把叶片的三个特征（轮廓、颜色、纹理）变成数字，通过比较特征距离来判断它"最像"哪一种植物。
用于课堂演示：关掉部分特征后，机器会很有把握地判错——这说明结论依赖证据。

## 在线访问

https://raidenlumine.github.io/feature-comparator/

## 本地运行

直接双击 `index.html` 即可，无需服务器、无需联网。

## 操作

| 操作 | 效果 |
|---|---|
| `1`–`4` | 切换待识别样本 |
| `M` | 手动填卡（照课堂卡片勾选） |
| `Q` / `W` / `E` | 开关 轮廓 / 颜色 / 纹理 |
| `R` | 重置 |
| `F11` 或双击 | 全屏 |

## URL 参数

锁定某一幕，便于排练：

- 正确识别：`?s=s1&f=111`
- 只开颜色（认错）：`?s=s2&f=010`
- 三特征全开（勉强认对）：`?s=s2&f=111`
- 手动模式（照卡片填）：`?m=1`
- 手动模式 + 指定选项：`?m=1&c=serrated,light,dense`

`s` 取值 `s1`–`s4`；`f` 三位分别对应轮廓、颜色、纹理，`1` 开 `0` 关；
`c` 三位分别对应 轮廓、颜色、纹理 的选项（`smooth`/`serrated`、`dark`/`light`、`sparse`/`dense`）。

## 手动填卡模式

课堂上学生填完纸质卡片后，按下 **M** 或点「手动填卡」，按卡片上的勾选逐项点选，
右侧会实时算出机器读到的那三个数字和判断结果。

卡片选项与数值的对应关系在 `js/data.js` 的 `manualMap` 中定义，可以按需要调整。

## 技术说明

纯静态、零依赖。特征值由真实叶片照片计算得出，比对使用欧氏距离，相似度按距离反比归一化。
这不是深度学习——三个特征是人手工设计的；真实系统里的特征由神经网络学习得到。
